<br>
<hr>
<br>
El Sistema de Gestión Hotelera (SGH) es una aplicación de escritorio integral diseñada para automatizar y optimizar las operaciones diarias de un establecimiento hotelero. El sistema proporciona una interfaz nativa e instalable en estaciones de trabajo que centraliza el control de habitaciones, inventarios, finanzas y reportes operativos en tiempo real.
Este proyecto ha sido desarrollado como parte del plan de estudios de la Universidad, sirviendo como base práctica para la aplicación de conceptos de arquitectura de 
software, diseño de interfaces, gestión de bases de datos.
